# What is the GloscBox?

The GloscBox is a console for playing games stored on physical media. Currently, the GloscBox only supports DVDs, CDs, and floppy discs.

The console runs linux, as well as my own custom game launcher called LIPGLOSC which attempts to emulate the feeling of playing on old consoles, like the Xbox 360 or PS3, by detecting an inserted DVD or floppy, and automatically launching whatever game is stored on it.
